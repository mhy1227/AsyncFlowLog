日志写入器模块解析

- LogAppender 定义写入契约，包括单条/批量 append、flush、生命周期管理与统计查询，是消费端与具体落盘实现的抽象边界（src/main/java/com/asyncflow/log/appender/LogAppender.java:11）。
- AbstractLogAppender 处理初始化状态、计数器与异常包裹，调用子类实现的 doAppend / doAppendBatch / doInitialize / doClose，确保公共逻辑一致并在写入成功后累加统计（src/main/java/com/asyncflow/log/appender/                       
  AbstractLogAppender.java:47,72,94,130,136,144,150,155）。
- FileAppender 作为默认实现，负责目录创建、按天轮转文件、线程安全写入与可选自动 flush。写入流程在进入锁后格式化事件（时间、线程、级别、类方法、异常）落入 BufferedWriter，并在日期跳变时重建文件句柄（src/main/java/com/asyncflow/
  log/appender/FileAppender.java:89,107,147,169,193,215,275）。
- LogEventHandler 实现 EventHandler，在初始化时保证 appender 就绪，消费线程调用 handle/handleBatch 完成写入并维护处理/错误计数，异常场景下尝试再次落盘并在关闭时触发 flush（src/main/java/com/asyncflow/log/appender/             
  LogEventHandler.java:17,48,63,83,108,122,131）。
- AppenderFactory 读取 async.log.appender.* 配置，当前支持 file 类型并生成 FileAppender，附带批量大小、刷新间隔、自动刷新等参数；AppenderConfig 在 Spring 启动阶段创建并初始化写入器 bean，提供给事件处理器和消费者使用（src/main/
  java/com/asyncflow/log/appender/AppenderFactory.java:13,57,74,92；src/main/java/com/asyncflow/log/config/AppenderConfig.java:26-37；src/main/java/com/asyncflow/log/config/EventHandlerConfig.java:31-35）。
- 在运行链路中，消费者线程池的 ConsumerTask 从事件队列取出 LogEvent 后交给 LogEventHandler，后者调用写入器完成持久化，与前述事件模块、队列模块形成闭环（src/main/java/com/asyncflow/log/consumer/ThreadPoolConsumer.java:226-242；
  src/main/java/com/asyncflow/log/appender/LogEventHandler.java:63-118）。
