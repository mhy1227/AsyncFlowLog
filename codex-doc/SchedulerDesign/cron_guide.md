# 定时任务 Cron 表达式速查（Spring/Quartz 样式）

> 适用范围：`@Scheduled(cron=...)`，Spring Boot 2.7（Spring 5.3）所用的 Quartz 风格 Cron（6 段，支持 `? L W #` 等）。

## 1. 语法总览（6 段）

| 字段 | 位置(自左) | 取值范围 | 说明 | 示例 |
|---|---:|---|---|---|
| 秒 | 1 | 0-59 | 支持 `*/n` 等步进 | `0`、`0/30` |
| 分 | 2 | 0-59 | 支持 `, - /` | `0`、`0/5`、`15,45` |
| 时 | 3 | 0-23 | 24 小时制 | `2`、`2-5` |
| 日 | 4 | 1-31 或 `?` | 月内第几天；与“周”二选一，其一需为 `?` | `1`、`L`、`1W`、`?` |
| 月 | 5 | 1-12 或 JAN-DEC | 可用英文缩写 | `*`、`JAN,MAR` |
| 周 | 6 | 1-7 或 SUN-SAT 或 `?` | 周内第几天；支持 `L`、`#`；与“日”二选一 | `MON-FRI`、`6#3`、`?` |

- Spring 常用为 6 段；“年”字段（第 7 段）通常不使用。
- `timezone` 通过注解或配置单独指定（见本项目 `async.log.maintenance.timezone`）。

## 2. 特殊字符

| 符号 | 含义 | 示例 | 解释 |
|---|---|---|---|
| `*` | 任意取值 | `* * * * * ?` | 每秒触发 |
| `,` | 枚举 | `MON,WED,FRI` | 多个离散取值 |
| `-` | 范围 | `1-5` | 连续区间 |
| `/` | 步进 | `0/15` | 从 0 开始每 15 单位 |
| `?` | 不指定 | `日` 或 `周` 二选一时，未参与匹配的一侧写 `?` | `0 5 2 * * ?` |
| `L` | 最后 | `L`(月末), `6L`(当月最后一个周六) | 月末/周内最后一个 X |
| `W` | 工作日 | `1W` | 当月 1 号最近的工作日 |
| `#` | 第 N 个周 X | `6#3` | 当月第 3 个周六 |

## 3. 常用表达式（场景速查）

| 场景 | Cron | 说明 |
|---|---|---|
| 每日 02:05 | `0 5 2 * * ?` | 推荐上线执行时间（避开 00:00 跨日） |
| 每日 00:00 | `0 0 0 * * ?` | 午夜执行 |
| 每 15 秒 | `0/15 * * * * ?` | 本地快速验证用 |
| 每 5 分钟 | `0 0/5 * * * ?` | 整 5 分钟执行 |
| 每小时整点 | `0 0 * * * ?` | 每小时 00 分 |
| 工作日 02:00 | `0 0 2 ? * MON-FRI` | 周一到周五 |
| 周末 03:00 | `0 0 3 ? * SAT,SUN` | 周六、周日 |
| 每月 1 日 02:30 | `0 30 2 1 * ?` | 月初归档 |
| 每月最后一天 02:00 | `0 0 2 L * ?` | 月末归档 |
| 每月第 3 个周六 02:00 | `0 0 2 ? * SAT#3` | `#` 表示第 N 个周 X |
| 每月 1 号最近工作日 02:00 | `0 0 2 1W * ?` | `W` 表示工作日 |

## 4. 在本项目中的使用

- 开关与时间：
  - `async.log.maintenance.enabled`（true/false）
  - `async.log.maintenance.cron`（见上表）
  - `async.log.maintenance.timezone`（如 `Asia/Shanghai`）
- 策略参数：
  - `async.log.retention.days`：删除阈值（含今天）
  - `async.log.archive.enabled|dir|days|compress`：归档开关/目录/阈值/压缩格式（zip）
  - `async.log.file.path`：扫描目录，需与写入器目录一致（如 `async.log.appender.file-path`）

示例（生产）：
```yaml
async:
  log:
    maintenance:
      enabled: true
      cron: "0 5 2 * * ?"
      timezone: "Asia/Shanghai"
    retention:
      days: 14
    archive:
      enabled: true
      dir: logs/archive
      days: 3
      compress: zip
    file:
      path: logs/async
```

## 5. 调试与常见坑

- 调试：本地可临时设为 `0/15 * * * * ?`，观察 `async-log-maintenance-*` 线程日志；验证后改回每日或关闭开关。
- `?` 的用法：当使用“日”字段时，“周”需写 `?`（反之亦然），避免含义歧义。
- 时区：务必显式设置 `timezone`，避免服务器默认时区导致错位；跨区部署注意夏令时。
- 权限与占用：Windows 上文件被占用可能删除失败；下轮重试或先释放句柄。
- 表达式校验：尽量使用 6 段（秒 分 时 日 月 周），不要附带“年”。
