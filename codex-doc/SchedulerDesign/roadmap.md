# 定时归档规划（Roadmap）

## 背景与目标
- 现状：本地 zip 归档 + 原始日志迁移（raw），重名追加时间戳，严格早于“今天”的历史文件才处理。
- 目标：在不打扰默认行为的前提下，逐步补齐合规、成本、可靠性与可观测能力，按需开关式演进。

## 场景与扩展点
- 合规/审计
  - 不可篡改/WORM、留存年限、法律保全；归档指纹（SHA256）与签名；操作清单（manifest）。
- 成本优化与分层
  - 本地 → 对象存储（S3/OSS） → 冷归档（Glacier/IA）；冷热分层策略与生命周期（自动转冷/删除）。
- 跨地域与容灾
  - 异地副本、跨 AZ 复制；RPO/RTO 目标；限速与错峰传输。
- 可检索归档
  - 旁路写索引（.idx）、按日/月层级目录；必要时落库 `log_archive` 便于检索。
- 安全与敏感信息
  - 归档加密（KMS/PGP），密钥轮换；必要的脱敏（PII 清洗）再归档。
- 可靠性与幂等
  - 原子写入（tmp → atomic move）、重试/退避、断点续传（远端）；重名策略（时间戳/跳过/覆盖）可配置。
- 过滤与阈值
  - include/exclude 多模式；min-bytes 跳过空/极小文件；最大单包与分片打包。
- 并发与集群
  - 分布式锁/ShedLock；任务分片（按日期/目录）；限并发与背压。
- 观测与报表
  - 归档/迁移/删除计数、字节数、耗时分布、失败率；完整性巡检（哈希校验）。
- 运维与清理
  - raw-dir 二次留存（7/14 天）后清理；磁盘水位触发保护（>阈值才归档/清理）。
- 命名与结构
  - 统一命名规范（服务/环境/日期/分片号）；按年/月/日分层，避免大目录。
- 恢复路径
  - 标准化解压/校验流程，定位清单（manifest），自助恢复指引与脚本。

## 优先级建议（最小改动优先）
1) 过滤与阈值：
   - min-bytes（跳过空文件/阈值以下文件）
   - include-patterns（多目录/多模式匹配）
2) 可靠性：
   - atomic-write（zip 先 .tmp 再原子移动）
   - 可选 verify（哈希校验后再迁移/删除）
3) 观测：
   - 归档/删除/错误计数与字节数指标，暴露至 Micrometer/Prometheus
4) 远端存储：
   - S3/OSS 后端与生命周期策略（冷存储/过期删除）

## 里程碑草案（可按需调整）
- M1（安全增强）
  - min-bytes、atomic-write、重名策略可配置（cover/rename/skip）
- M2（匹配与指标）
  - include/exclude 模式；指标与仪表盘（Prometheus/Grafana）
- M3（远端与生命周期）
  - S3/OSS 上传 + 生命周期管理；断点续传与限速
- M4（合规与审计）
  - 签名/指纹与 manifest；WORM/留存策略对接

## 兼容性与默认策略
- 默认保持当前行为：本地 zip + 原始迁移（raw），重名追加时间戳；仅处理严格早于今天的文件。
- 新能力通过配置开关启用，避免对现网产生不必要影响。
